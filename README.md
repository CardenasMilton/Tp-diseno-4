# Coffea — Landing page

Landing page estatica de la cafeteria ficticia Coffea. HTML5 y CSS3, sin JavaScript.
Trabajo practico 4 — Diseño UX-UI

## Estructura
- index.html: pagina unica con las 9 secciones.
- 404.html: pagina de error.
- css/: tokens, base, layout, componentes y utilidades.
- assets/: imagenes e iconos.
- netlify.toml: configuracion de despliegue.

## Convenciones
- Nomenclatura BEM (.product-card, .product-card__title).
- Colores, fuentes, radios y espacios definidos en css/tokens.css.
- Mobile-first con media queries min-width.
- Capas de CSS: tokens, base, layout, components, utilities.

## Levantar en local
1. Clonar el repositorio.
2. Abrir index.html en el navegador (o usar Live Server de VS Code).

## Despliegue
Sitio estatico en Netlify, con deploy continuo desde la rama main.
